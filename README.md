# Отсутствие сходимости популярных методов оптимизации в машинном обучении

В проекте реализованы и численно исследованы методы стохастического градиентного спуска, тяжелого шарика Поляка, ускоренного градиента Нестерова и Adam. Эксперименты проводятся на тестовых функциях и датасете Iris с целью анализа необходимости теоретических условий сходимости.


## Структура
- `experiments/`: содержит 4 Jupyter Notebook файла с экспериментами:
  - `convergence_examples_sgd.ipynb`: для стохастического градиентного спуска;
  - `convergence_examples_hb.ipynb`: для метода тяжелого шарика Поляка;
  - `convergence_examples_nag.ipynb`: для ускоренного градиента Нестерова;
  - `convergence_examples_adam.ipynb`: для метода Adam;
  - `iris_classification_hb.ipynb`: для метода тяжелого шарика Поляка на датасете Iris.

- `src/`: содержит модули с реализациями алгоритмов оптимизации и вспомогательными функциями для вычислений и визуализации.

## Запуск экспериментов
1. Создать виртуальное окружение.

2. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```

3. Перейти в папку `experiments`:
   ```
   cd experiments
   ```

4. Запустить эксперименты.
